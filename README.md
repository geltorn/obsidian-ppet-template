# PPET Template для Obsidian

## 📚 Что такое Obsidian?

**Obsidian** — это мощное приложение для работы с заметками, которое хранит данные в виде обычных текстовых файлов в формате Markdown. Ключевые особенности:

- **Локальное хранение** — все заметки хранятся на вашем устройстве в виде простых `.md` файлов
- **Связность** — возможность создавать связи между заметками через вики-ссылки `[[Название]]`
- **Расширяемость** — богатая экосистема плагинов для автоматизации и кастомизации
- **Будущее-proof** — ваши данные останутся читаемыми даже без Obsidian

## 💡 Ценность этого шаблона

Этот шаблон предоставляет **готовую систему управления знаниями и задачами** для продуктивной работы:

| Преимущество | Описание |
|--------------|----------|
| **Структура** | Готовая организация заметок по типам: люди, проекты, встречи, задачи, материалы |
| **Автоматизация** | Скрипты для быстрого создания сущностей без ручного ввода |
| **Связность** | Автоматическое связывание встреч, задач и материалов с людьми и проектами |
| **Агрегация** | Динамические списки встреч и задач через плагины Dataview и Tasks |
| **Гибкость** | Легко адаптируется под личные или командные нужды |

**PPET Template** (People, Projects, Events, Tasks) таким образом позволяет связывать людей, проекты, задачи, встречи и рабочие материалы.

Автоматизированные возможности:
- организация базы людей со списком встреч, задач и рабочих материалов по ним
- организация базы проектов со списком встреч, задач и рабочих материалов по ним
- планирование и заведение встреч с привязкой к людям и\или проектам
- создание рабочих материалов с привязкой к проектам, людям и встречам
- ведение списков задач с разбиением по людям с сортировкой по дедлайну
- ежедневные заметки со списками встреч в этот день и задач

## 🚀 Как установить 

### Шаг 1: Установка Obsidian

1. Скачайте Obsidian с официального сайта: [https://obsidian.md/download](https://obsidian.md/download)
2. Установите приложение для вашей ОС (Windows, macOS, Linux, iOS, Android)
3. Запустите Obsidian

### Шаг 2: Открытие хранилища в Obsidian

1. В Obsidian нажмите **"Open folder as vault"** (Открыть папку как хранилище)
2. Выберите папку с шаблоном (папка этого репозитория)
3. Нажмите **"Open"** (Открыть)

### Шаг 3: Включение плагинов

При первом открытии хранилища Obsidian предложит выбрать режим работы с плагинами:
 Нажмите **"Trust"** (Доверять) — все необходимые плагины уже установлены в репозитории
Для правильной работы требуется вручную включить настройку включения плагина Templater при создании нового файла (правильное срабатывание дат). Нужно зайти в Настройки Templater и включить пункт "Trigger Templater on new file creation".

### Шаг 4: Персонализация

1. Откройте файл `AGENTS.md` и заполните его в соответствии со своей ролью и проектами
2. Настройте шаблоны в папке `Templates/` под свои нужды
3. При необходимости измените скрипты в `_Scripts/`

## 🚀 Как пользоваться
В ленте слева добавлены 4 основные кнопки 📅 🔨 ➕ 👤, которые служат для вызова команд создания основных сущностей.
Также можно использовать и копировать в нужные места кнопки из текста ниже.

```meta-bind-button
label: Новый человек
icon: plus
style: primary
hidden: false
action:
    type: js
    file: "_Scripts/New person.js"
```
👤 Кнопка "Новый человек" создает в папке "Люди" заметку, в которую агрегируется вся информация о встречах и задачах связанных с человеком.
Кнопка через плагин MetaBind связана с командой "QuickAdd:Новый человек", которая запускает скрипт Scripts/New person.js


```meta-bind-button
label: Новый проект
icon: plus
style: primary
hidden: false

  - type: js
    file: "_Scripts/New project.js"
```
➕ Кнопка "Новый проект" создает в папке "Проекты" заметку, в которую агрегируется вся информация о встречах и задачах связанных с проектом.
Кнопка через плагин MetaBind связана с командой "QuickAdd:Новый проект", которая запускает скрипт Scripts/New project.js


📅 Кнопка "Добавить встречу" запрашивает дату встречи, ее тип (Встреча 1-1, Встреча по проекту, Обычная встреча) и создает в папке "Встречи" по соответствующему шаблону (шаблоны находятся в папке Templates) заметку, в которой можно как проводить подготовку к будущей встрече, так и записать информацию о проведенной. Команда учитывает активную открытую заметку, считывает с нее свойство type и создает соответствующую встречу. Например, если активная заметка по человеку, то будет создана встреча по этому человеку.
Кнопка через плагин MetaBind связана с командой "QuickAdd:Добавить встречу", которая запускает скрипт Scripts/New meeting.js

Созданные встречи можно найти в заметке по человеку\проекту\ежедневной заметке(по дате встречи). Для получения списков встреч используется плагин Dataview. Созданные задачи аналогично находятся в заметке по человеку или проекту, а также в заметке [[_Все задачи]]. Для получения задач используется плагин Tasks, с документацией можно ознакомиться [здесь](https://publish.obsidian.md/tasks/Introduction).

📄 Кнопка "Добавить материал" создает в папке "Материалы" рабочую заметку с привязкой к проекту или человеку. Скрипт учитывает активную заметку — если открыт человек или проект, материал будет автоматически привязан к нему. Также можно привязать материал к встрече.
Кнопка через плагин MetaBind связана с командой "QuickAdd:Добавить материал", которая запускает скрипт Scripts/New material.js.

**Структура материала:**
- **Дата** — дата создания (автоматически)
- **Связано** — ссылка на проект или человека
- **Встреча** — опциональная ссылка на встречу
- **Контекст** — предыстория и проблема
- **Содержание** — основное содержание заметки
- **Решения** — принятые решения
- **Ссылки** — связанные ресурсы
- **Action items** — задачи по материалу

**Темы материалов:** Архитектура, Исследование, Решение, Черновик, Конспект, Другое (список можно изменить в скрипте New material.js)

Материалы отображаются в заметках людей и проектов в секции "Рабочие заметки" через плагин Dataview.
Также задачи и сроки выполнения удобно смотреть в виде доски в плагине CardBoard - для открытия такой доски есть кнопка 📋. Задачи на такой доске группируются по тегам. Пример приведен в шаблоне. Для изменения нужно нажать значок Настройки около вкладки Задачи. Можно создавать несколько досок.

### AI-агент CLI — универсальный помощник
Для работы с базой знаний можно использовать любой универсальный агентский CLI — например **Claude Code** или **Qwen Code**. Агент читает контекст из файла `AGENTS.md` и помогает создавать встречи, задачи, людей, проекты и материалы, а также анализировать заметки.

Установите агентский CLI по официальной документации выбранного инструмента (Claude Code, Qwen Code и др.).

В Obsidian подключён плагин **Terminal**, который позволяет запускать агентский CLI прямо из заметок.
По умолчанию терминал настроен на macOS zsh. Эти настройки возможно нужно скорректировать, если вы используете другую ОС или другую оболочку. Посмотреть и изменить настройки можно здесь: `.obsidian/plugins/terminal/data.json` или в UI — Настройки ➡️ Terminal ➡️ Profiles. Также командой `which claude` / `which qwen` полезно проверить, где установлен ваш агент.
Для Windows нужно настроить аналогичный профиль.

**Файл `AGENTS.md`** содержит контекст проекта для AI-агента:
- Описание пользователя и его роли
- Продукты и команды
- Метрики
- Структура базы знаний
- Правила работы и создания артефактов

> **Важно:** Каждый пользователь должен дополнить `AGENTS.md` в соответствии со своей ролью и окружением — добавить свои проекты, команды, метрики и правила работы.

### Структура
```
├── _Archive/ # Архивные заметки
├── _Attachments/ # Прикрепленные файлы
├── _Scripts/ # Скрипты для QuickAdd
│ └── *.js # Скрипты для различных задач
├── Встречи/ # Заметки о встречах
├── Дневник/ # Ежедневные и еженедельные заметки
├── Люди/ # Заметки о людях
├── Материалы/ # Рабочие материалы (заметки по проектам и людям)
├── Проекты/ # Заметки о проектах
├── Templates/ # Шаблоны для заметок
```
