## 📜 Система автоматизации Obsidian

### Скрипты QuickAdd (`_Scripts/`)

| Скрипт | Назначение |
|--------|------------|
| `New meeting.js` | Создание встреч (1-1, по проекту, обычные) с автоопределением типа по активному файлу |
| `New task.js` | Добавление задач с тегами из текущей заметки, дедлайном и опциональным тегом человека |
| `New person.js` | Создание заметки человека с тегами, контактами и ссылками |
| `New project.js` | Создание заметки проекта с тегами и ссылкой |
| `New material.js` | Создание рабочего материала с привязкой к проекту/человеку и опционально к встрече |

### Структура заметок

#### Человек (`Люди/{Имя}.md`)
```yaml
---
tags: [тег человека по формату 1-1_Имя]
type: Человек
---
```
**Содержание:**
- Логин, email, ссылка на профиль в мессенджере
- Кнопка MetaBind для создания встречи
- Dataview-список встреч по тегу
- Tasks-список задач по тегу

#### Проект (`Проекты/{Название}.md`)
```yaml
---
tags: [основной тег проекта]
type: Проект
---
```
**Содержание:**
- Ссылка на проект, описание
- Кнопка MetaBind для создания встречи
- Dataview-список встреч по тегу
- Tasks-список задач по тегу

#### Встреча (`Встречи/{YYYY-MM-DD}-{Имя/Проект}-Встреча.md`)
```yaml
---
tags: [тег человека/проекта]
Дата: YYYY-MM-DD
Тема: 1-1 / Встреча по проекту / Встреча
link: [[Человек/Проект]]
---
```
**Типы встреч:**
- **Встреча 1-1** — привязка к человеку, шаблон с повесткой и action items
- **Встреча по проекту** — привязка к проекту, шаблон с решениями по проекту
- **Обычная встреча** — шаблон с участниками, целями, таблицей обсуждения

**Логика создания:**
1. Выбор даты (сегодня или вручную)
2. Автоопределение типа встречи по активному файлу (если открыт человек/проект)
3. Генерация уникального имени файла (добавление `(1)`, `(2)` при коллизиях)
4. Замена шаблонной даты `2026-04-28` на выбранную
5. Добавление тега и ссылки на человека/проект во frontmatter

#### Ежедневная заметка (`Дневник/{YYYY-MM-DD}.md`)
**Содержание:**
- Dataview-список встреч за день
- Список задач
- Комментарии

#### Рабочий материал (`Материалы/{Проект/Человек}-{Тема}.md`)
```yaml
---
tags: [тег проекта/человека, тематический тег]
Дата: YYYY-MM-DD
Связано: [[Проект/Человек]]
Встреча: [[YYYY-MM-DD-Встреча]] (опционально)
---
```
**Содержание:**
- Контекст — предыстория и проблема
- Содержание — основное содержание заметки
- Решения — принятые решения
- Ссылки — связанные ресурсы
- Action items — задачи по материалу

**Темы материалов:** Архитектура, Исследование, Решение, Черновик, Конспект, Другое

**Логика создания:**
1. Выбор даты (сегодня или вручную)
2. Выбор проекта/человека (автоопределение по активному файлу)
3. Выбор темы (из списка или свободный текст)
4. Опционально: привязка к встрече
5. Генерация уникального имени файла
6. Добавление тега и ссылок во frontmatter

#### Задача
**Формат:**
```markdown
- [ ] Текст задачи 📅 YYYY-MM-DD #тег1 #тег2 #Мои_задачи ✅ 2026-04-23
```
**Логика добавления:**
- Основной тег берётся из текущей заметки
- Опционально: тег `#Мои_задачи`
- Опционально: тег человека (выбор из папки `Люди/`)
- Дата исполнения: по умолчанию +7 дней

### Используемые плагины

| Плагин | Назначение |
|--------|------------|
| **Templater** | Шаблоны заметок с динамической датой `2026-04-28` |
| **Dataview** | Динамические списки встреч и задач с фильтрацией по тегам |
| **QuickAdd** | Автоматизация создания заметок и задач через скрипты |
| **MetaBind** | Интерактивные кнопки для создания встреч |
| **Calendar** | Визуализация заметок по датам |
| **Tasks** | Управление задачами с дедлайнами |
| **Commander** | Централизованный доступ к командам |
| **Terminal** | Интеграция терминала в Obsidian для работы с CLI-инструментами и агентским CLI |

### Правила для агента при создании артефактов

При запросе пользователя создать **встречу**, **задачу**, **человека** или **проект**, следуй логике скриптов, скрипты ты не запускаешь, создаешь файлы сам.

#### Создание человека
1. Спроси имя, логин, основной тег (формат: `#1-1_{Имя}`)
2. Укажи email и ссылку на профиль в мессенджере
3. Создай файл `Люди/{Имя}.md` с frontmatter и структурой

#### Создание проекта
1. Спроси название, основной тег (формат: `#Проект_{Название}`), ссылку
2. Создай файл `Проекты/{Название}.md` с frontmatter и структурой

#### Создание встречи
1. Спроси дату (YYYY-MM-DD), тип (1-1/по проекту/обычная)
2. Для 1-1: выбери человека из `Люди/`, возьми тег из файла
3. Для проекта: выбери проект из `Проекты/`, возьми тег из файла
4. Имя файла: `Встречи/{YYYY-MM-DD}-{Имя/Проект}-Встреча.md`
5. Добавь тег и `link: "[[{Человек/Проект}]]"` во frontmatter

#### Создание задачи
1. Спроси текст, дату исполнения (по умолчанию +7 дней)
2. Добавь теги: основной из заметки + опционально `#Мои_задачи` + опционально тег человека
3. Формат: `- [ ] текст 📅 дата #теги`

#### Создание материала
1. Спроси проект/человека (автоопределение по активному файлу)
2. Выбери тему (Архитектура/Исследование/Решение/Черновик/Конспект/Другое)
3. Опционально: привяжи к встрече
4. Имя файла: `Материалы/{Проект/Человек}-{Тема}.md`
5. Добавь тег проекта/человека и ссылки на связанный объект и встречу во frontmatter, ссылку нужно ставить вот так, не забудь кавычки - например 
   ```
   Связано: "[[Люди/Человек]]"
   ```
или
```
Связано: "[[Проекты/Проект]]"
```

#### Создание дайджеста
1. Спроси за какой день нужен дайджест
2. Используй доступные вам инструменты (например, сбор данных из переписки) и собери сводку по дню
3. Добавь заметку с дайджестом в ежедневную заметку в папке Дневник
#### Важно! 
Когда добавляешь теги во frontmatter не используй символ тега # и пробелы!
